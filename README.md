# Sudoku Deathmatch

Jeu multijoueur dans le navigateur, de 2 à 4 joueurs. L'arène est une grille de
Sudoku : chaque joueur déplace un bonhomme sur la grille et remplit des cases,
qui prennent sa couleur. La partie se termine quand la grille est pleine ou
qu'il ne reste qu'un bonhomme.

En conception : rien ne se lance encore. Les règles sont écrites au fur et à
mesure dans `Docs/Design/00-Game.md`, l'architecture dans
`Docs/Design/01-Architecture.md`.
